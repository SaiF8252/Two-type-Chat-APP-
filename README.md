📌 Two-Device Chat App (Node.js + Socket.io)

A simple real-time chat application using Node.js, Express, Socket.io, and Multer for file uploads. Supports multiple devices, active user list, file sharing, and message seen indicators.

🚀 Features

🔗 Real-time chat using Socket.io

👤 Active users sidebar

🖼 File uploads (images, PDFs, videos, etc.) with 25MB limit

✅ Message seen status

🔒 Guest or saved username support

🌐 Multi-device support

🛠 Technologies Used

Node.js

Express.js

Socket.io

Multer (for file uploads)

HTML/CSS/Vanilla JS frontend

Local file storage (/uploads)
